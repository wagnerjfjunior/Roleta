# Roleta — SFJM Boundary

## Projeto

`wagnerjfjunior/Roleta` é autoridade para:
- estado do projeto Roleta;
- regras do domínio;
- metodologia estatística do projeto;
- dados e evidências versionados;
- handoffs e próxima ação segura.

## Protocolo

`wagnerjfjunior/StopJuniorMode` é autoridade para o protocolo SFJM.

## Workspace

`wagnerjfjunior/sfjm-workspace` pode representar Roleta como visualização/continuidade derivada.

```text
ROLETA_CANONICAL_STATE > WORKSPACE_DERIVED_STATE
WORKSPACE_ADOPTION != ROLETA_MUTATION_AUTHORITY
SFJM_PROTOCOL != ROLETA_PRODUCT_STATE
```

Qualquer divergência deve ser resolvida em favor do repositório canônico do domínio correspondente.
