# Evidence Index

Fontes primárias do projeto incluem:
- fotos das folhas físicas;
- PDFs de roletas;
- planilhas estruturadas anteriores;
- arquivos consolidados derivados.

Regras:
- evidência visual direta > transcrição auxiliar;
- transcrição automática ou análise antiga não substitui a folha original;
- cada correção deve apontar para a fonte;
- duplicatas e quarentenas permanecem documentadas.
